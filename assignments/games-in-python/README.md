# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Create a Hangman game where players guess letters to reveal a hidden word before running out of attempts. Build the classic word-guessing game using Python strings, loops, and user input.

**Skills practiced:** String manipulation, loops, conditionals, random selection

## 📝 Tasks

### 🛠️ Hangman Game

#### Description
Build the classic word-guessing game in Python.

#### Requirements
Completed program should:

- Randomly select words from a predefined list
- Accept letter guesses and show current progress (_ _ _ format)
- Track incorrect guesses remaining
- End when word is guessed or attempts exhausted
- Display win/lose messages
